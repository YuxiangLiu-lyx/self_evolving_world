# ex6: Behavioral Analysis

Reviewer: Current Codex conversation (implementing-agent self-review, not independent approval). Task: pr-17-development-coevolution. Recommendations are analysis only; no world, prompt or agent change is authorized by this report.

## Summary

One real gpt-6.1-sol run reached all 180 synchronous rounds with three healthy survivors, without rescue, parameter tuning or a selective rerun. All three requested cultivation in their first decision; subsequent requests addressed recovery and finite construction material. These were model-initiated choices under development goals, not inventions independent of model prior knowledge. Implemented effects became 38 persistent objects, 41 consumed cultivated meals (738 nutrition), 315 additional realized recovery energy, and shared use by other actors. Production alone is not benefit: 116 generated units and 196 physical effect events include unused stock. No model weights were trained.

The run used 59/120 ordinary attempts, 12/20 world attempts and three accepted current-conversation development declarations. Reported usage is 594,836 input and 29,262 output tokens, with two failed attempts lacking usage; recorded call time totals 993,637 ms. Internal Codex development calls/tokens are unavailable, not zero. The ten-intervention proxy does not establish compliance with an exact ten-model-call development budget. Source-validation and stale-handoff failures precede the persisted declaration ledger and are retained separately. This is an exploratory joint-mechanism observation, not a causal estimate of development goals, project memory, ecology or facilities.

Public registered abilities are intentionally shared world knowledge; their reuse is not evidence of message transmission. Same-round decisions derive from one start snapshot. ## Causes

The direct mechanisms support narrow statements: eating a traced generated stack increased nutrition, resting within a platform's scope increased capped recovery, and an actual generated branch was consumed to construct a later planting. Source/state/event traces establish these local consequences. They do not isolate why an actor chose the request or how many actions would have been needed under a different world.

The initial72 food units plus starting reserves already supported an offline180-round survival path. Survival therefore cannot be credited to cultivation alone. Larger reserves, connected starts, development goals, project persistence, energy costs, executable facilities and continuing implementation all changed together relative to ex5. Comparing ex5 deaths with ex6 survival is not a controlled treatment effect. The reviewed root/berry delays and global public registry also shape observed differences. LLM prior knowledge explains why cultivation was proposed before the actors had extensive lived experience; the evidence supports autonomous selection within the provided interface, not novel discovery by a blank learner.

## Limitations

This is one seed, one model family, three actors and one180-round window. Persistent plans and project text are self-reports supplemented by actual actions; they do not reveal internal intent. Finite growth lifetimes, one stationary object per cell,48 total objects, three ecological niches and bounded recipes define an artificial physical envelope. There is no dismantling/reuse of exhausted planting cells in this version. Branch growth records finite biomass output but zero edible nutrition, not zero physical energy. The nursery feedback cycle was observed through material reinvestment; second-generation consumption was not reached. Longer-term replacement under material/space exhaustion is untested.

Five ordinary/world attempts were failed or rejected: a malformed world result and timeout at2, two malformed world replies at116, and an ordinary transport failure at177. They remain in the12/59 totals. A separate world result explicitly requested development. Two failures lack token telemetry. The three accepted development records count current-conversation declarations, not internal calls. Declaration validation failures are counted when persisted, but source-validation failures and stale task responses occur before that ledger write; the retained failed architecture-validation log and task journal expose this gap. No exact total development call/time/token cost or zero-cost claim is justified. All known offline/CI work is separate from real inference.

Replay capture initially failed because the old test assumed one resource stack per map cell and because auxiliary source evidence was outside the archive whitelist. The fix displays summed quantities, checks exact per-cell resource IDs for global/private views and explicitly hashes narrowly named source artifacts. Capture-only retries did not reissue inference or change the observed world. Full final acceptance and current remote gates remain delivery requirements; the implementing conversation's analysis is self-review, not independent scientific approval.

## Proposed improvements

1. Run one preregistered maintenance experiment with the final interpreter frozen and a longer observation window, retaining failed or budget-paused outcomes. The most consequential unresolved question is whether agents maintain supply after finite planting lifetimes, branch depletion and occupied space accumulate. ex6 reached material reinvestment but not sustained consumption from that second generation; another short attractive sample would not resolve that bottleneck. Verification: Before execution, fix the horizon, feasible initial supply, attempt limits and stop conditions without reusing ex6 agent plans. Do not add new base effects or rescue resources during the run; record unsupported requests and retained pauses. This proposal is analysis only and has not been executed.
