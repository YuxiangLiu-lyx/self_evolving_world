Physical and interface friction consumed attention: occupied navigation destinations, worksite overlap with the performer, whole-unit material constraints, compact summaries omitting exact owned identities, and incorrect operation/reference forms. The real Cedar 4 reference failure contained an embedded space; an isolated positive control succeeds with the existing exact resolver, so the world model's asserted ownership bug was not patched. Public calls 290 and 367 incorrectly placed six member identities in one proposal field; both were rejected and charged without changing personal plans. The source-bound bark feedback/detail repair at round 56 retained earlier defective behavior and the uncertain terminated call. New diagnostics and inventory access arose from actual later requests, without relaxing collision or granting supplies. The authored queue limits attention fairly but produces real waiting; that waiting is not disposable leisure. Frequent replanning plus large contexts used the frozen token allocations before the requested horizons.

## Limitations

Short B ended at 37 rounds and continuation remained below one 200-round season, so long-term survival, full seasonal adaptation, stable division of labor, civilization, intergroup institutions and sustained production gains remain unproven. A was shorter and underwent generic transport/context repairs before B started. This is an exploratory bundled-architecture observation, not a matched-horizon or component-causal estimate. Current-run public capability reuse is not actual teaching. Cooperation messages require corresponding transfers and subsequent use before benefit is claimed. No-model fixtures establish conservation, shared use, death/cancellation, restore and physical effects; none counts as autonomous formal behavior. Known token ratios omit unknown provider usage and all unmetered current-conversation preparation, development and review. Model output contains concise reasons and projects, not evidence of hidden deliberation or weight training. The global replay is for human inspection and is not a model packet.
