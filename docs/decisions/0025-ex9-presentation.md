# ADR 0025: Independent ex9 presentation replay

- Status: Accepted
- Date: 2026-11-22

## Context

Final presentation needs a close, readable forest view of real ex9 actions. The
research inspector remains valuable for complete evidence. Importing a game
engine or replacing the map would obscure the experimental boundary.

## Decision

Add `/ashen.html` with isolated presentation code and a small attributed Ashen
asset subset. Reuse the existing archive-owned verified replay worker, continuous
coordinates and pure geometry queries. Never install capabilities, mutate a
snapshot, write an archive or invoke a model from this page.

Bind bookmarks to actual retained events. Separate approval, personal study,
reserved paid work, produced inventory and equipped use. Draw enclosures from
actual wall and doorway geometry, and show no unbuilt fire or canopy. Use only
safe adjacent recorded movement for interpolation; otherwise snap. Camera,
lighting and cosmetic poses cannot alter world time or outcomes.

Keep the original viewer, with one navigation link and optional round/actor URL
parameters for exact return. Register the new browser scenes in the existing
continuous validation group; archive preservation and current CI remain required.
Retain presentation evidence outside historical experiment archives.

## Consequences

The extra art is requested only by the preview page. Terrain and sprite decoding
are cached, and paused views redraw on state/camera changes. The preview reuses
verified prefix cancellation and bounds playback work to a ten-frame window around the selected boundary.

The continuous presentation refinement uses one animation-frame clock for motion,
gait, work and speed changes, plus a separate damped follow camera. A missing
verified frame freezes presentation time rather than accumulating catch-up debt.
Objects and outputs change only at integer saved boundaries. A paused fractional
pose is labeled as between boundaries; exact stepping and seeking reset it.
Fullscreen and optional drawers remain confined to this entry. Dynamic acceptance
measures rendered feet, gait phase and camera movement across round and segment
boundaries, alongside actual recording review; heartbeat timing alone is insufficient.

The art set and buildings are intentionally modest. Tile river edges, recorded
rectangular footprints and sparse paths remain constraints. This is an ex9-only
visual layer; it makes no claim of new experiment behavior or exact historical
character appearance.
