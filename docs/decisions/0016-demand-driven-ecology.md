# ADR-0016: Demand-driven Ecology in a Versioned Physical Envelope

- Date: 2026-11-09
- Decision status: Accepted

## Context

ex4 demonstrates constrained generated skills over a closed material catalogue and activity-specific operations. The next task requires heterogeneous starts, unknown food risk and genuinely new resource/mechanic definitions without rewriting archived experiments or executing unrestricted generated code.

## Decision

Add evolution-v1 and replay/archive version5. Reuse base snapshots, vision and simultaneous movement, typed learning actions, external response transport, durable task handoffs and archive/delivery gates. Separate schemas describe arbitrary bounded resource types, one-time habitat-conditioned ecological allocations and executable extraction/consumption/conversion/identification compositions. The World Agent proposes definitions; pure code validates and applies them. Individual learning and private discovered properties remain actor-local.

Keep four comparable actors, a fixed 120-round protocol and finite attempts. Run an explicitly simulated smoke before allocating live ex5. Preserve unsuccessful decisions and deaths, with no mid-run condition changes. Persist the complete world ledger and reconstruct replay without models.

## Alternatives and reasons

Hardcoding fishing or fruit-request branches would imitate evolution while leaving every higher-level behavior authored. Arbitrary host-language execution or autonomous core edits would demand a much larger isolation and governance architecture. A general constrained state-transition envelope permits new types, recipes, distributions and compositions while enforcing finite quantities, costs and immutable metabolism. A separate version avoids silently changing ex1–ex4 semantics.

Per-request rerolls and per-new-type generation could create infinite food. One persistent allocation per physical site, including zero, prevents that loophole conservatively. Ecological refinement cannot refill existing sites. Shared functional signatures avoid duplicate implementations but do not replace semantic review.

## Costs and future consequences

Supported physics remain finite primitives; natural process changes, species coexistence and unrestricted interaction code need later versioned design. Resource feasibility and free-text disclosure rely partly on actual World Agent judgment. Same prompt/different surroundings can produce distinct paths without establishing personality or causal intelligence. The longer ledger uses a bounded larger archive allowance, while replay remains under the existing import bound. Old schemas and immutable archives remain independent compatibility contracts.
