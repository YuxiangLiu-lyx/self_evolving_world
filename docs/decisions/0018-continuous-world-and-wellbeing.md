# ADR-0018: Continuous World and Event-grounded Wellbeing

Date: 2026-11-19

Status: Accepted

## Context

ex6 demonstrated paid persistent objects and shared use, but its grid, fixed operation vocabulary, short plans, source allowlist and finite process ceilings constrained further development. The next user-authorized experiment requests a continuous world, a game presentation and autonomous happiness-driven behavior over a longer observation, while retaining the existing task and delivery framework.

## Decision

Introduce an independent continuous-v1 kernel behind public world-core exports. Deterministic simultaneous transactions combine continuous swept geometry, private-knowledge navigation, physical costs, persistent state/processes and bounded event-grounded wellbeing. Public implementation and individual learning remain separate. New reviewed packages may add mechanisms, schemas, spatial behavior, lifecycle, rendering and private memory adapters through the existing current-conversation handoff.

The application owns model transport, persistent actor tasks and pre-counted shared budgets. Repository adapters own immutable call/round journals, source manifests, exact prefix reconstruction, segmented archives and the existing validation/PR/merge continuation. The viewer reconstructs saved world state and never advances a live simulation. A historical presentation adapter preserves old discrete records.

## Alternatives

Increasing ex6 constants would retain its expression and lifecycle limits. Replacing the task framework would discard already working acceptance and provenance. A free-form interpreter would require a new untrusted-code sandbox and weaken source review. Renderer interpolation alone would fail the requested physical-space change. None is selected.

## Reasons

Separate versioning preserves all previous experimental rules and archives. Registered executable code removes arbitrary operation ceilings while programmatic invariants, complete tests, source preservation and old-prefix reconstruction maintain reviewability. Persistent conditional tasks reduce inference frequency without embedding a survival strategy. Actual event-triggered satisfaction permits repeated enjoyment without rewards for descriptions, requests, mastery or skill count.

## Costs

Swept geometry, atomic shared actions and live source versions increase testing and replay cost. Route search uses a numerical mesh and conservative rectangle expansion. Extensions remain trusted reviewed host code, not sandboxed arbitrary code. Development-internal inference usage is unavailable and must be reported as unknown. A long observation may pause before its target when a shared budget or computational protection is exhausted.

## Future consequences

Later observations can extend a saved world without resetting actor identities or budgets while preserving prior windows. More complex activity or presentation requests require actual reviewed implementations and prerequisites. The protocol does not predeclare those outcomes or isolate their causal effects. Legacy protocols and their catalogue remain unchanged. See the [protocol](../CONTINUOUS_WORLD.md) and [execution plan](../exec-plans/completed/pr-18-continuous-world.md).
