# ADR-0023: Collective Attention with Private Member Contexts

Date: 2026-11-22

Status: Accepted

## Context

The continuous engine already separates physical identities, individual learning,
fresh package scopes and persistent operations. Ex10 also demonstrated that
unbounded capability and observation context can consume the input guard before
the intended window. A larger population needs shared attention without granting
omniscient group knowledge or replacing personal intentions.

## Decision

Add an optional collective policy to the current engine. Retain independent actors
and the existing same-start transactional barrier. Construct individual inputs
from personal observations and public coordination from actual reports, using
fresh requests to the same model endpoint. Public output is a proposal settled
after physical actions; it never writes actor tasks. Communication, report access
and teaching remain paid local actions. Group scopes do not grant mastery.

Use one fair attention queue per group, bounded waiting and explicit phase call
and token ceilings. Journal reservations before transport and preserve unknown
usage. Extend the existing task coordinator with a small sequential A/B adapter;
reuse the existing handoff, capture, window-preservation and delivery gates.
No historical experiment changes behavior when collective policy is absent.

## Alternatives and consequences

A prompt asking a controller to ignore secrets is not an information boundary.
Per-member per-round inference scales cost with population. Shared inventory or
instant mastery would erase the cost of cooperation and teaching. A separate
campaign service would duplicate the working coordinator and recovery contracts.

The public capability register and attention rules are authored experimental
conditions, not emergent social institutions. Bounded views may require lookup
actions. Short allocations can end before 200 rounds; retain that actual window
before beginning B's separately reserved continuation allocation. No unused
allocation transfers and no state resets. The bundled comparison supports
descriptive evidence, not single-
component causal attribution or guaranteed civilization. See the
[protocol](../COLLECTIVE_LIFE.md) and
[plan](../exec-plans/completed/pr-25-collective-life.md).
