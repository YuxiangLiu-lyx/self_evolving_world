# ADR-0021: Versioned Execution and Sustained Experience

Date: 2026-11-21

Status: Accepted

## Context

Ex8 retained actual alias failures, repeated completed sampling and outgoing-message interruptions. Its operation cursor already advanced on completion and its material escrow and navigation repairs were real. The next authorized experiment combines execution clarity, dietary experience and moderate environmental pressure without prescribing agent discoveries.

## Decision

Select new behavior with immutable `config.experience`, retaining previous forest and continuous transitions. Resolve declared item/object/category references before all handler dispatch, bind ongoing operation arguments, expose actual progress and validate generated contracts. Qualify received message interruption without changing the synchronous barrier.

Keep slow mental state separate from physical wellbeing and transient pleasure. Actual meals use conserved intake and canonical ingredients, with substantial-episode aggregation and bounded feedback. Maintained event sources accumulate slowly and decay; all effects remain observable and replayable. Recovery modifies continuous effort/recovery values, never basic nutrition or integer task repetition.

Use the existing scenario, kernel, current-conversation development barrier, source snapshots and scoped acceptance. Preserve ex8 capabilities as implemented public functions requiring new individual study. Fix the 1,200-round policy and 650/60/20 budgets before the first formal call; retain failed calibration and formal outcomes separately.

## Alternatives

Prompt-only reference instructions leave inconsistent executors. Globally changing forest-v1 invalidates historical evidence. Treating total happiness as recovery efficiency double-counts hunger and fatigue. Novelty-only bonuses force activity choices. A new experiment/task framework duplicates existing durable barriers and review.

## Reasons

One resolved identity and complete-execution semantics reduce ambiguous intent without choosing a strategy. Neutral mental dynamics avoid punishing the absence of rewards. Physical composition and actual costs make later functional improvements measurable. Independent configuration preserves historical reconstruction and clear version boundaries.

## Costs

The combined observation cannot isolate causal effects. Trusted generated handlers still require real code and conservation review. Fixed primitive food properties and accelerated ecology simplify the world. The omniscient offline oracle proves feasible behavior, not learnability. Developer-internal usage and monetary cost remain unknown.

## Future consequences

The observed round-495 continuation failure requires operation bindings to outlive plan replacement. The versioned dispatcher stores exact paid identity/progress in actor state; declared reference arrays share the same alias rules. Terminal work is never reconstructed. Requested portable insulation, fire, willow processing and rain interception and paid recuperation retain separate paid physical state and central event-based reward settlement. Further processing and social mechanisms require explicit physical contracts. Novel useful activities can enter the current development handoff; no outcome is required for experiment acceptance. Subsequent parameter changes require another retained run. See [protocol](../FOREST_EXPERIENCE.md) and [plan](../exec-plans/completed/pr-23-forest-experience.md).
