# Round 15: worksite examination after real placement failures

Lin independently requested examination of an unplanted footprint after overlap
and bare-ground eligibility failures. The actual requested point (9.25, 12.9) is
forest terrain. The general local `ordinary soil` regime describes moisture and
hazards; the first planting implementation accepts only exposed bare ground. This
is partly an interface/model limitation, not evidence that forest soil cannot grow
plants. The accepted `world-33` review requests a minimal physical examination.

`soil-worksite-assessment@1` costs one study round, then one examination round and
0.5 energy per started attempt. It requires a reachable visible in-bounds footprint;
invalid invocations never start work. It shares the exact original planting site
predicate, preserving the original order and every prior error. It reports actual
modeled surface evidence, visible overlap and provisional operation compatibility,
with deeper substrate, hidden occupants, viability and future conditions unknown.
The private dated record is not a physical transformation or guaranteed planting
site. No root, material, terrain, ownership, mastery or reward changes.

The neutral presentation outline binds only an actual completed examination event
and the recorded footprint. It does not display a constructed object. The one-round
examination is atomic like baseline observation: there is no unfinished escrow,
automatic revisit, maintenance or resumable work. A later examination pays again.

Targeted fixtures reproduce Lin's actual forest-floor coordinates, contrast the
bare patch used by Moss, verify study, payment, inaccessible-target rejection,
unchanged material/terrain, private records, repeat costs and fresh-scope isolation.
These fixtures do not establish autonomous use. In final analysis this diagnostic
must be separated from a new productive capability and from interface repair;
its presence alone is not evidence of improved food supply.
