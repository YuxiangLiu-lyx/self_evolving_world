# Ex12 development 7: physically assessed fractional root preparation

World-309 at round 95 jointly reviewed independent requests from Birch 3 and
Birch 5. Both questioned a fixed one-unit bark prerequisite after real fractional
extraction and a rejected preparation attempt. One shared `root-preparation@2`
package implements assessment and small setup, rather than duplicating crushing.

The existing `root-preparation` interface retains its original operations and
active processes. The new operations require separately learned
`root-preparation-surface`, with `root-preparation` mastery as prerequisite and one
additional study round. The new study identity is necessary because the existing
engine tracks personal interface mastery, not per-operation mastery: merely
upgrading a world package must not silently teach every existing practitioner.
The old interface dispatches its added operations through the same gated handler;
legacy explicit process IDs continue through the old implementation. No personal
state changes during installation.

Paid assessment uses the actual selected bark and stone, costs 0.2 energy and a
round, and checks a clear reachable firm support patch. A single unfragmented
extraction-derived bark lot can receive the explicitly reviewed fallback geometry:
density 500 kg/m3, thickness 0.003 m, rectangular aspect ratio 1.5. Represented
geometry takes precedence. Dimensions, connectedness, holes, condition, actual
mass, origin, evidence basis and uncertainty are retained. The actual 0.3-unit
request contains 0.09 mass; quantity is applied exactly once. Combined separate
lots are not joined sheets, and fines are not inferred continuous. A flexible,
intact usable 0.16 by 0.16 metre rectangle and an actual stone of intrinsic
hardness at least 3 are required. This is a containing sheet on firm support,
not a free-standing impact structure. Model dimensions are never described as
personal measurements.

Preparation reserves the entire selected real sheet, one reusable stone and only
the chosen 0.1–1.0 original root quantity in exact tenths. Two work equivalents and
two energy per root preserve proportional effort for a fractional last increment;
discrete environment time still advances normally. Each paid increment checks
actual reach, collision, support conditions, tool and energy. Leaving or losing
conditions pauses paid progress while food continues aging. Completion, explicit
cancellation, expiry and death release the same physical material once. Root
composition, nutrients, toxins, age and partial crushing reuse the existing
physics; complete crushed food ages at 1.25 baseline without nutrition, safety or
preservation improvement. The unreserved second root is not processed.

New personally established assessment and trial facts use the existing canonical
understanding source and its unchanged caps, cooldown and maintenance. Ordinary
crushing, requests and mastery receive no added award, and duplicate practice
awards are explicitly excluded for these findings. Repeated equivalent evidence
is deduplicated. The shared geometry, root composition, escrow, cancellation and
feedback code are attributed reuse, not independently reinvented mechanisms.

Five targeted tests and four retained-failure regressions pass, including the real
round-95 bark record. They cover quantity and age, the untouched second root,
proportional work, pause/checkpoint/resume, changed-input rejection, one-time
completion, cancellation/death, disconnected/undersized/fines/tool/site failures,
canonical reward deduplication, separate study and active legacy continuation.
Four browser frames show assessment, partial work, completion and cancellation,
with explicit model uncertainty, selected quantity, paid/remaining work and actual
crushing fraction. These are fixtures, not formal behavior. Full unfiltered unit,
type, architecture, build and exact 95-round reconstruction remain mandatory
before activation. No frozen environment or budget is retuned; internal coding
usage remains unknown, not zero.

The counted handoff passed all 720 tests across 95 files, types, architecture,
build and exact 95-round reconstruction with identical world and event hashes.
Source revision 7 was activated at the saved barrier, and the same real run
continued. No round advanced during implementation or validation.
