## Reviewed boundaries

- `collective-policy`, `collective-types`, `collective-social`, the scenario,
  controller and input modules preserve physical member identities. Public
  packets use dated reports; personal packets use the selected observation.
  Shared control deliberately sees its own group's observed union. Independent
  requests have no prior response chain. The public register is an authored
  institution; it is not evidence that agents invented knowledge sharing.
- The kernel and registry changes protect individual state during migration,
  gate learning on actual current-world capability knowledge, retain the
  transactional round and update experience from real events. Public proposals
  settle after that round and never assign personal cursors.
- The scheduler reserves a slot only at an actual attempted invocation. Age
  priority precedes urgency once a member is overdue; failed public calls retain
  reports and their retry interval. Token reservations include the serialized
  request and bounded output. Preserved continuation counters prevent unused
  short allocation from expanding the long phase.
- Replay adapters restore personal intent and public settlement before comparing
  exact state hashes. Archival request verification uses integrity-checked
  retained revisions and exact attempt prefixes, including same-round repairs.
  It performs no inference and is explicitly not a security sandbox.
- Reviewed processing adapters use actual owned allocations and persistent paid
  work. Root crushing conserves nutrition and increases exposed decay; drying
  has reversible weather-dependent moisture and measured decay accounting.
  Branch peeling conserves output, fines and residual composition. No installation
  supplies stock or mastery. Generic implementation reuse is attributed separately
  from independent formal requests.
- Viewer additions use group colors, actual member records and real work state.
  Private member inspection suppresses other members' carried processing output;
  whole-world inspection remains a human tool. Mechanism fixture visuals and
  actual experiment captures are reviewed separately.
