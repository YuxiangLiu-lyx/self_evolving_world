# Ex12 development 6: conservative material supply combination

At round 90, Ash 1 had actually produced two separate 0.7-unit bark supplies.
The existing tray interface requires one addressable unit. World call 294 approved
`material-stack-combine@1`, with one personal study round, as a conservative
aggregation operation. Its practical need follows prior paid extraction; neither
aggregation nor the later tray is counted as a formal success before actual use.

This ex12-only interface validates 2–16 distinct, owned, unlocked supplies and
compares canonical resource, intrinsic profile, unit mass, physical form and
represented processing. Different origins and ages remain separate flat original
lots. It pays one active round and 0.5 energy and commits once inside the existing
atomic action barrier. Events expose the original reservation, one remaining work,
exact costs, output identity and zero remaining work after commitment. Status
reports actual source versions; optional expected versions must match all inputs.
Cancellation/death releases unsettled original identities once. No benefit,
understanding or generic practice source is awarded by ordinary aggregation.

This minimal version accepts passive materials, including the two actual bark
supplies. Edible blends, manufactured equipment and active treatment need an
explicit combination law; copying one constituent's processing effect to all
material is prohibited. This is a physical representation limit, not an activity
or era whitelist. In the existing engine, unlocked owner-attributed inventory is
carried even if its old production coordinates remain; ground stacks have no
private owner and reservations are excluded. Ground supplies require actual pickup
first. No new owned-ground representation or remote access is invented.

Component records retain original identities, quantities, physical and chemical
profiles, age, origin and processing history. Aging and spoilage operate on each
actual lot using the parent item's actual location. No averaging rejuvenates old
material. Partial reservation and physical transfer take stable exact slices.
Tray work consumes ten tenths of an addressable fourteen-tenths supply, leaving
four tenths with the correct original history; stone, labor and site requirements
remain unchanged. Legacy stacks acquire a one-lot representation only when needed.
The generic ex11 escrow and shared reference implementation are attributed code
reuse, not inherited mastery or independent reinvention of those helpers.

Seven targeted mechanism tests and three retained-failure regressions passed.
The latter include an isolated positive control using the exact two round-90
archived sources, without mutating that checkpoint. Other tests cover mass and
history, paid work and zero reward, exact tray slices, cancellation/death,
transfer/pickup/nested combination, stale/foreign/locked/incompatible inputs,
per-lot spoilage, checkpoint identity and experiment/personal isolation. An initial
fixture incorrectly placed a tray on its existing standing-tree fixture; moving
that unrelated fixture obstruction out of the selected site fixed setup, without
weakening collision checks.

Four browser scenes cover actual selection, combination, downstream reservation
and cancellation. Initial visual inspection found old bark labels overlapping a
new task and provenance disclosure collapsing on resize. The viewer now keeps
that disclosure open with bounded scrolling and hides the older bark overlay after
later combination work. A browser assertion was updated to respect this real
persistent open state instead of blindly toggling it closed. Fixtures remain
explicitly labeled and are never included in formal decision contexts.

Full unit, type, architecture, build and exact 90-round reconstruction are required
by the handoff before activation. Frozen resources, parameters, budgets and all
previous experiment archives remain unchanged. Internal development tokens are
unobservable, not zero.

The counted handoff passed all 714 tests across 94 files, types, architecture,
build and exact reconstruction of every saved round with identical world and
event hashes. It activated source revision 6 at the round-90 barrier before the
same real run resumed. The four final provenance/quantity frames were personally
inspected after the disclosure fix and the browser test passed.
