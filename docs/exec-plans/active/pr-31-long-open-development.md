## Scope and exclusions

Reuse the existing continuous kernel, experiment registry isolation, task coordinator,
OAuth/model transport, development handoff, verified replay and scoped acceptance.
No A/B campaign, collective population expansion, new paid service, model-weight
training, fixed technology tree, outcome-driven rescue or historical archive edits.
A separate technical probe is allowed only if necessary, at most one 30-round run;
prefer retained real usage plus offline request replay. It must never become formal
experimental evidence. No probe has been launched.
