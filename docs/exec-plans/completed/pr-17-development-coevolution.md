# PR-17: Development Motivation and World Coevolution

## Requirement summary

Run the next retained real experiment with three autonomous actors and a target of 180 synchronous rounds. Observe whether health, reliable supply, less repetitive work and better living conditions motivate functional requests that become useful executable world changes. This is exploratory joint-mechanism evidence, not a requirement to build/cooperate or a causal estimate of any one mechanism. Preserve the existing task coordinator, acceptance, PR and guarded merge workflow.

Add a separate coevolution protocol and only the adapters needed to route, reconstruct and display it. The founding catalogue/base skills and ex1-ex5 behavior remain unchanged. The initial task intent uses the existing evolution route solely to enter preparation. Before preparation submission it will be amended to the new protocol route; no evolution-v1 experiment is authorized or run by that temporary routing choice.

## Acceptance criteria

1. Deterministic preflight records food amount, legal first-food distances, sustained acquisition/consumption/rest schedules, connected starts and common-area access, with all three surviving 180 rounds under an explicitly simulated feasible policy.
2. Mechanism fixtures demonstrate atomic material costs, no duplicated stock/energy, persistent shared benefits, coexistence without rerolls, cross-round processing and bounded attempts; old archive reconstruction remains exact.
3. The actual model run ends at the horizon, preregistered stop, or a retained budget/environment pause. Scientific disappointment is an outcome, not a reason to rerun. A pause cannot be described as reaching the target horizon; its complete observation archive may proceed through delivery. Failed required checks still block delivery.
4. Stage reports and final evidence tie each claimed improvement to actual states and uses. Authored eating, fixtures and conversation implementation are disclosed separately.
5. Complete automated and real visual/semantic review evidence precedes reviewed commit, current-head PR policy and quality, authorized merge and independently verified completion.

## Limitations and follow-up

Reported ordinary/world usage totals594836 input and29262 output tokens, with two attempts missing telemetry. Recorded call time totals993637ms. Three accepted current-conversation development declarations are measurable; internal model calls/tokens are unavailable, not zero. Declaration rejections are counted when persisted, while source-validation failures and stale task submissions precede that ledger write and remain separate retained gate failures. The ten-intervention proxy is not an exact ten-model-call guarantee or a complete cost account.

Finite typed effects are a physical envelope, not unrestricted physics. The initial food already permits180-round survival; a joint single run cannot isolate any mechanism or establish that cultivation caused survival. No messages, gifts, carrying tools or delayed processors were used in the real run. Public material/facility use is observable cross-actor influence, without evidence of negotiated cooperation. Recommend one separately authorized, preregistered longer maintenance experiment with the final interpreter frozen, measuring second-generation meals and material/space exhaustion. No follow-up run has been executed.
