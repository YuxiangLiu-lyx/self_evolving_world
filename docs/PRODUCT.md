# Product Feature Inventory

This is the single authoritative source of feature status. Other documents describe behavior and link here instead of maintaining separate status tables.

`Retired` means removed; the row is kept for history. `Planned` means not implemented; `In Progress` means implementation is underway; `Implemented` means delivered but not fully accepted; `Validated` means the listed acceptance checks passed. Validation applies only to the recorded environment and evidence. It does not imply production readiness or completed human review.
